# PorchPong App Store submission copy

This copy reflects the free default and the current iPhone experience. Administrator-enabled features are complimentary grants, not purchases.

## Description

PorchPong brings your household's packages together in one place. Forward order confirmations and shipping updates to your private household address, then see what's on the way, what needs attention, and what has arrived.

- Review packages, delivery estimates, and the original emails behind each update.
- Share one package view with your household while keeping each household's data separate.
- Get optional delivery notifications and add a private package calendar to Google Calendar or a calendar subscription.
- Mark packages collected, correct details, and keep track of changes.

PorchPong is free to download and use with email forwarding. Eligible households can connect Gmail on the web and receive carrier API tracking when an administrator enables those features for their account.

## App Review notes

PorchPong is free to download and use. Any verified Google account can sign in and create a household. After signing in, open Settings to copy the household forwarding address; forwarding an order confirmation or shipping update creates package updates. Google Calendar and notifications are optional.
